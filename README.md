# Master Fire Prediction

This repository contains code developed as part of my master's thesis in Applied datatechnology and engineering at Western Norway University of Applied Sciences.

The project focuses on retrieving and processing weather data from MET Norway's Frost API for use in fire prediction.

## Current status

- Project setup completed
- Frost API connection working
- Initial weather observations retrieved

## Project structure

- `src/` - Python source code
- `notebooks/` - exploratory notebooks
- `data/` - local data files
